# Chat App

A monorepo for a chat application built with React + Vite for the frontend, Express for the backend, and Prisma for shared database access.

## Project Structure

- `client/` — React + Vite frontend
- `server/` — Express backend API
- `packages/shared/` — shared Prisma client, database schema, and shared types

## Prerequisites

- Node.js 20+ (or latest stable compatible with TypeScript 6)
- PostgreSQL database
